# Mwaki Experience

🔗 **Live Demo:** [https://mwakidemo.vercel.app/](https://mwakidemo.vercel.app/)

A premium 3D restaurant/lounge website for "Mwaki Experience" located in Bhopal. Built with React, Vite, Three.js, Framer Motion, and Tailwind CSS.

## Features
- **3D Hero Section**: Custom interactive 3D stylized glass and glowing embers built with React Three Fiber and Drei.
- **Cinematic Animations**: Smooth scroll reveals using Framer Motion.
- **Premium UI/UX**: Dark theme with warm amber/gold accents and glassmorphism.
- **Responsive**: Fully functional mobile-first layout.
- **WhatsApp Integration**: Working reservation form that constructs a pre-filled WhatsApp message.

## Setup Instructions

1. **Install Dependencies**
   Run the following command to install all required packages:
   ```bash
   npm install
   ```

2. **Run Development Server**
   Start the local dev server:
   ```bash
   npm run dev
   ```

3. **Build for Production**
   To create a production build:
   ```bash
   npm run build
   ```

## Technologies Used
- React + Vite
- Three.js (@react-three/fiber, @react-three/drei)
- Framer Motion
- Tailwind CSS
- Lucide React (Icons)
